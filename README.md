# Smart Money Manager 💰

Smart Money Manager is a simple and user-friendly personal finance management application built with Python and SQLite. It helps users track their daily income, expenses, and overall balance easily.

## 🚀 Features
* **Income & Expense Tracking:** Record and categorize daily earnings and spending.
* **Balance Overview:** View total income, total expenses, and remaining balance at a glance.
* **Database Storage:** Uses SQLite (`money_manager.db`) to safely store all financial records locally.
* **Clean Interface:** Easy-to-use layout designed for quick money management.

## 🛠️ Technologies Used
* **Language:** Python
* **Database:** SQLite (`money_manager.db`)

## 💻 How to Run the Project
1. Clone or download this repository to your computer.
2. Open the terminal or command prompt inside the project folder.
3. Run the application using the command:
   ```bash
   python app.py
   ```
   *(Note: If you used Streamlit or Flask to build `app.py`, run `streamlit run app.py` instead.)*
